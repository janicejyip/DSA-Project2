<H1> CineSort (COP3530 - Project 2) </h1>

To run the code, download the MovieLens 32M dataset from [here](https://grouplens.org/datasets/movielens/).
Unzip the file into the resources folder. Depending on your setup, you may need to adjust the file paths in main.cpp. The current file paths are meant to be read from resources/ml-32m/(file) using CLion's run code feature.
